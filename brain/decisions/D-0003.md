# D-0003: project commands = the smoke suite

Date: 2026-11-11
Reversibility: easy

## Context
This repo has no package.json (deliberate: kit scripts are stdlib-only .mjs),
so no script table to discover.

## Decision
`commands.test` and `commands.run` are both `node scripts/smoke.mjs` — it is
the kit's real executable check (structural contracts, syntax, encoding rules).
No lint/build: none exist.

## Alternatives considered
- Leave commands empty (lose the automatic verification hook).
