# D-0002: bilingual convention — English structure, Spanish summaries

Date: 2026-11-11
Reversibility: easy

## Context
Maintainer wants both languages in the brain (user choice), but fully bilingual
files double the tokens of every read — against the project's token-economy
golden rule.

## Decision
Node frontmatter, criteria, and evidence stay in English (what agents parse
every turn). The human-facing summary (index "at a glance", one line per
decision) carries a Spanish one-liner. `language: en` in config.

## Alternatives considered
- Everything bilingual (2x token cost on every read).
- Spanish only (inconsistent with the kit's English artifacts).
