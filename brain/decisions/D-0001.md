# D-0001: clean start — no adopt mapping

Date: 2026-11-11
Reversibility: easy

## Context
Dogfooding decision for the kit repo: map existing skills/agents as nodes, or
start empty.

## Decision
Clean start, chosen by the maintainer. The brain holds only new M/L work; the
historical record already lives in CHANGELOG.md and per-skill verification
contracts. Mapping existing files would duplicate that record and create drift
risk on day one.

## Alternatives considered
- `adopt` full mapping (heavier, duplicates CHANGELOG).

*Español: arranque limpio — la historia queda en el CHANGELOG; el brain solo para trabajo nuevo.*
